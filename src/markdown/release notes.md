# Release Notes For goLF framework

We are excited to announce the release of goLF framework version 1.0.0! This release brings several new features to improve your development experience.

### Features
- Include support for Databases through Env variables and also allow continuous monitoring
- Database supported:
   - Postgres
   - Redis
   - Elastic search
- support for Configs Management basing APP_ENV.
- support for Inbuild Metrics and also custom Metrics.
- support for Logs(colored logs with Log level).
- support for Microservice calls using inbuilt functions.
- support for basic validations.

- https://github.com/LetsFocus/goLF/wiki
